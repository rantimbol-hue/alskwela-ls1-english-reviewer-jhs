# ALSKwela JHS LS1 English — Option-Balanced v2.0 (16 November 2026)

## What changed
- 86 of 120 multiple-choice items have revised option wording to reduce answer-length clues.
- Original correct-answer letters, competencies, difficulty labels, questions, stimuli, correct/incorrect feedback, and professional Taglish explanations are retained.
- Average correct-option length: 10.40 -> 9.24 words; average distractor length: 7.50 -> 9.11 words.
- Unique longest correct option: 74 -> 19 of 120; no question has an option-length range above 5 words.
- The 120 embedded items have been synchronized to the Excel/CSV/JSON bank.
- PWA `id`, URL scope, icons, naming, and local-storage keys are unchanged.
- `sw.js` uses a new cache version to replace offline content on the learner's next online visit.

## GitHub update (same URL, existing repository)
1. Extract the ZIP onto your computer. Do NOT upload the ZIP itself into the GitHub repository.
2. Open https://github.com/rantimbol-hue/alskwela-ls1-english-reviewer-jhs
3. Choose `main` branch (the branch already publishing the live Pages site).
4. Use Add file > Upload files. Select `index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, and `.nojekyll` from the ZIP. GitHub may ask to replace same-name files; commit changes.
5. Confirm Settings > Pages still publishes from `main` and `/(root)`; do not create a new repository or change the ALSKwela link.
6. Open https://rantimbol-hue.github.io/alskwela-ls1-english-reviewer-jhs/ directly in Chrome with internet on; refresh twice or completely close/reopen app to allow the updated service worker to activate.
7. Start a NEW trial (old unfinished trials retain the former wording) and test feedback, randomized 40-question mode, PDF export.
8. Turn on airplane mode, reopen via the same Home Screen shortcut/app, and verify a practice question still loads.

**Do not delete app storage or reinstall merely to update questions.** If the offline version remains old, visit online and refresh twice. Clearing site data removes locally saved progress.
